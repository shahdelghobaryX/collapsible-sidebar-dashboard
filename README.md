
# Collapsible Sidebar Dashboard

A responsive collapsible sidebar dashboard built using HTML, CSS, and JavaScript as part of my Front-End Web Development internship.

## Features

- Expandable and collapsible sidebar.
- Five navigation links with icons.
- Interactive navigation between dashboard sections.
- Smooth CSS transitions and animations.
- Responsive layout for mobile screens.
- Active navigation link highlighting.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome

## Project Structure

collapsible_sidebar/
├── index.html
├── style.css
├── script.js
└── README.md

## How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
